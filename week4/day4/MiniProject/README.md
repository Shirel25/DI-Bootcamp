# Apple Stock Analysis – Time Series & Trend Exploration 📈🍏

This project explores Apple stock price dynamics through time series analysis and financial data visualization.

## 🎯 Objectives

- Analyze historical Apple stock data
- Visualize trends in price, volume, and volatility
- Apply time series techniques for trend exploration
- Build preliminary predictive models using moving averages and regression

## 🧰 Tools & Libraries

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## 📊 Highlights

- Cleaned and prepared stock data
- Visualized long-term stock performance
- Detected patterns in volatility and volume
- Used regression and hypothesis testing to explore statistical insights

- `apple.ipynb` – Full notebook with code and plots
