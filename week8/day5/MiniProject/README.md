# Data Job Market Insights – Trends, Salaries & Skills 📊

This project presents an interactive Tableau dashboard built using real-world job postings data to explore hiring trends in the data industry.

## 🎯 Objectives
- Analyze demand for key data roles (Data Scientist, Data Analyst, Data Engineer)
- Compare salaries across roles and locations
- Identify most in-demand skills and top hiring companies
- Explore monthly trends and industry patterns

## 🧰 Tools
- Tableau  
- Excel / CSV data  
- Data cleaning and preparation in Tableau  

## 📊 Key Features
- Role and salary comparison  
- Skills most requested in job offers  
- Top hiring locations and companies  
- Interactive filters for job title, location, and industry  
- Bubble charts, bar charts, line graphs, and treemaps
